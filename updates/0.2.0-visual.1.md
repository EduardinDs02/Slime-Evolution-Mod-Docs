## The first visual rework

The first visual pass builds on the functional release candidate. Six primary slimes receive integrated hierarchies and atlases with observed idle, jump, damage, and feeding actions. Six priority artifacts gain dimensional models. Interfaces, blocks, other species, and broader polish remain work in progress at this historical stage.
