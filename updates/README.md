# Atualizações por versão

[Guia do mod](../README.md)

Esta seção registra o que mudou em cada lançamento. Para consultar como jogar,
use os guias da [documentação do mod](../README.md).

| Versão | Principais mudanças |
|---|---|
| [0.14.2](0.14.2.md) | Documentação e imagens em repositório público próprio; novo endereço na Slimepedia. |
| [0.14.1](0.14.1.md) | Guia em GitHub Pages, acesso pela Slimepedia e banner panorâmico. |
| [0.14.0](0.14.0.md) | Identidade visual e animações de Celestial, Cristal Energizado, Almas, Pântano, Micélio, Lama, Obsidiana e Supercélula. |
| [0.13.0](0.13.0.md) | Circuito do Elétrico, sonar do Cristal, relé do Cristal Energizado e vitrine do Vidro. |
| [0.12.0](0.12.0.md) | Onze funções individuais, cinco conquistas de linhagem e seis estruturas renovadas, com altares e arenas protegidas. |
| [0.11.0](0.11.0.md) | Corrupção iridescente animada, crateras pelo corpo do Lunar e movimento do sol do Solar. |
| [0.10.0](0.10.0.md) | Aura esférica do Eclipse, espinhos do Ferrofluid, oito fases lunares e fumaça distribuída no Steam. |
| [0.9.0](0.9.0.md) | Funções individuais: aquecimento, compostagem, guia submarino e armazenamento no Âmbar. |
| [0.8.0](0.8.0.md) | Vínculo, treinamento, ordens aprendidas e simbiose entre espécies |
| [0.7.3](0.7.3.md) | Interfaces SolarPunk detalhadas, prévias 3D, indicadores e navegação mais clara |
| [0.7.2](0.7.2.md) | Blocos SolarPunk com volume, máquinas orientáveis, painéis animados e ninhos detalhados |
| [0.7.1](0.7.1.md) | Itens SolarPunk em 3D e Slimepedia com abertura e leitura com as duas mãos |
| [0.7.0](0.7.0.md) | Quinze espécies adquiridas, novos cruzamentos, metamorfoses ambientais e habilidades |
| [0.6.0](0.6.0.md) | Cristais variados, cabelos em tecido, flores, rocha magmática e efeitos mais visíveis |
| [0.5.0](0.5.0.md) | Detalhes dos slimes, bosses maiores, novos efeitos e invocações |
| [0.4.0](0.4.0.md) | GeckoLib, materiais elementais, asas e interfaces SolarPunk |
| [0.3.0](0.3.0.md) | Mais padrões de bosses, esquadrão real e deformação do gel |
| [0.2.0 — visual.4](0.2.0-visual.4.md) | Corpos em gota e efeitos contínuos |
| [0.2.0 — visual.3](0.2.0-visual.3.md) | Correção de bosses invocados por comando |
| [0.2.0 — visual.2](0.2.0-visual.2.md) | Modelos para todas as espécies |
| [0.2.0 — visual.1](0.2.0-visual.1.md) | Primeiro conjunto visual |

Os registros mantêm os números e as limitações de sua própria versão.
Valores atuais de vida, dano e armadura estão em [balanceamento](../BALANCE.md).
