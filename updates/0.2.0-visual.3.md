## Command-summoned boss fix

Bosses summoned with commands could ignore Survival players because missing arena positions were assigned before command placement. Missing arena origins are now initialized on the first AI tick at the correct position. Explicit saved arenas, including the world origin, remain intact; NoAI still intentionally disables AI. Damage, ritual costs, IDs, hitboxes, and schemas are unchanged.
