# Slime Evolution 0.22.0

[Version history](README.md) · [Player guide](../README.md)

- Fixes combat continuity for all four bosses: brief visibility tolerance, eligible companion targets, and recovery after displacement beyond the inner arena boundary. Twelve prolonged-combat cases cover attacks, minions, cover, and arena return.
- Rebuilds all six structures using the Minecraft Builder skill and preview review: inhabited castle wings and roofs, an enclosed circular temple, a cathedral with full facades, an L-shaped library and observatory, a lake cabin with curved boardwalks, and an ellipsoidal cavern. Routes to all six reward chests were checked in Minecraft.
- [Gallery, comparison, and building skill](../guides/SPECIAL_STRUCTURES.md).

New builds require new chunks; existing generated structures are not replaced. Update both client and server. GeckoLib 4.9.3 remains required.
